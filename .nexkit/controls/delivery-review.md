# Axis independent application review

Read the approved issue, AGENTS.md, docs/product-brief.md, accepted architecture,
the actual candidate diff and all recorded check results for that candidate.
The implementation report and previous reviews are claims to verify against
source and evidence. This fresh session is read-only.

Assess whether the complete requirement is satisfied and whether assertions
meaningfully verify it. Inspect relevant data validation, workflow execution,
compatibility, access control and audit behavior. Check that E2E exercises the
real application and that required test reports contain successful cases.
Missing, stale, empty, failed or skipped checks do not establish acceptance.

Give concrete, actionable findings with exact file references. Request changes
when the candidate or evidence does not meet the approved requirement. Do not
change source, broaden scope, manufacture human approval or treat this review
as the owner's PR approval. Keep unrelated project references out of the result.
