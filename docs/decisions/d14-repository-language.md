# D14. Repository language

Status: **Agreed**

## Context

The owner may write in Vietnamese, while contributors, agents and the tools that read the repository
work best in one shared language.

## Decision

Everything in the repository and on GitHub is in English: code, comments, configuration, docs,
commit messages, issues and pull requests.

## Consequences

- A request the owner writes in Vietnamese is restated in English before it enters an issue, a pull
  request or a doc.
- An application's text resources for another language, such as the samples' `vi` texts, are
  content in that language, not repository prose.
